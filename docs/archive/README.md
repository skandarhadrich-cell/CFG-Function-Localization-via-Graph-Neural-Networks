# Archived plans

The files in this directory are historical. They are kept so the evolution of the
project is visible, but they are **not** the current methodology.

- `legacy-two-stage-plan.html`: the original four-class, class-0, two-stage plan.
  It is superseded by the current `README.md` and
  `docs/labeling_contract.md`. In particular, the current project has no class 0,
  uses three independent sigmoids, and treats unmatched CAPA functions as weak
  negatives or unlabeled, not as a benign category.

For the current design, start with [the README](../../README.md).
